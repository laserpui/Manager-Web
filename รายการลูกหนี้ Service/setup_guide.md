# 🔧 คู่มือตั้งค่า Google Apps Script (ฉบับปรับปรุง)

## ทำไมต้องมี Apps Script?
การอัปเดต "สถานะ" / "หมายเหตุ" และลบข้อมูลบน Google Sheet จากหน้าเว็บ ต้องใช้ **Google Apps Script** เป็น API ตัวกลาง

---

## ขั้นตอนที่ 1: เตรียม Google Sheet

เปิด Google Sheet ของคุณขึ้นมา → เพิ่มหัวคอลัมน์ใน Row 1:
- **คอลัมน์ M** → พิมพ์ `จำนวนเงิน`
- **คอลัมน์ K** → พิมพ์ `สถานะ`
- **คอลัมน์ L** → พิมพ์ `หมายเหตุ`

---

## ขั้นตอนที่ 2: สร้าง Apps Script

1. เปิด Google Sheet ของคุณ
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** → **Apps Script**
3. ลบโค้ดเริ่มต้นเก่าทั้งหมดออก
4. เปิดไฟล์ [code.gs](code.gs) ในโฟลเดอร์นี้ แล้ว **คัดลอกโค้ดทั้งหมดไปวาง**
5. กด **Ctrl+S** หรือ **⌘+S** เพื่อบันทึกโครงการ
6. ตั้งชื่อโปรเจกต์ เช่น `AR Service API`

*(หมายเหตุ: โค้ดเวอร์ชันนี้จะดึงไฟล์ชีตอัตโนมัติด้วยคำสั่ง `SpreadsheetApp.getActiveSpreadsheet()` ทำให้ไม่ต้องกรอก Sheet ID หรือ URL อีกต่อไป)*

---

## ขั้นตอนที่ 3: Deploy เป็น Web App

1. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน → เลือก **การทำให้ใช้งานได้แบบใหม่ (New deployment)**
2. คลิกไอคอน ⚙️ (ประเภทของการจัดวาง) ด้านบนซ้าย → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **คำอธิบาย**: `AR Service API`
   - **ดำเนินการในฐานะ (Execute as)**: เลือก **ฉัน (Me)**
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: เลือก **ทุกคน (Anyone)**
4. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. ทำตามขั้นตอนของ Google เพื่ออนุญาตสิทธิ์เข้าถึง (Authorize Access) ของระบบ
6. **คัดลอก URL ของเว็บแอป** ที่ได้ (จะมีลักษณะ: `https://script.google.com/macros/s/xxxxx/exec`)

---

## ขั้นตอนที่ 4: ใส่ URL ใน admin.html

เปิดไฟล์ `admin.html` → ค้นหา `APPS_SCRIPT_URL`:

```javascript
const APPS_SCRIPT_URL = '';
```

แก้ไขโดยนำ URL ที่คัดลอกมาวางในเครื่องหมายอัญประกาศ:

```javascript
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/xxxxx/exec';
```

---

## ✅ เสร็จแล้ว!

หลังตั้งค่าเรียบร้อย ฟังก์ชันเหล่านี้จะใช้งานได้ทันที:
- 💵 บันทึกและแสดงจำนวนเงิน (คอลัมน์ M)
- ✏️ แก้ไขข้อมูลเดิมในคอลัมน์ B–J และ M โดยคงประทับเวลา สถานะ และหมายเหตุเดิมไว้
- 📝 อัปเดตสถานะ (คอลัมน์ K) 
- 📝 อัปเดตหมายเหตุ (คอลัมน์ L)
- 🗑️ ลบแถวข้อมูลออกจากชีตแบบ Real-time

> [!WARNING]
> หากมีการแก้ไขโค้ด Apps Script ใหม่ในอนาคต ต้อง **Deploy เวอร์ชันใหม่** ทุกครั้ง (เลือก New deployment เพื่อแก้ไขและทำให้ใช้งานได้) โค้ดใหม่จึงจะมีผลใช้งาน
